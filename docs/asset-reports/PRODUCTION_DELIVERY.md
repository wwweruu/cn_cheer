# 战场地形与棋子动画交付

2026-09-06。依据用户追加的 C1 参考图与“额度以内直接制作动画”授权，将木质棋盘更换为连续泥土战场，并为 14 类棋子接入静置、攻击、受击、退场与行进动作。原始高模、8K 母版贴图和完整底座均保留。

启动 `npm run dev -- --port 4175` 后：

- [游戏](http://127.0.0.1:4175/)：32 枚独立运动的棋子，可实际走子、吃子、悔棋和重开。
- [动作检视](http://127.0.0.1:4175/motion-gallery.html)：14 类棋子、三档精度、六段动作；支持暂停、时间轴与速度控制、旋转和 GLB 下载。
- [动作近景合览](motion/all-motion-contact.png)：修订后的 14 类棋子攻击姿态。
- [静态模型检视](http://127.0.0.1:4175/asset-gallery.html)与[源高模](http://127.0.0.1:4175/master-review.html)仍可查看。

## 战场

以 `象棋3D参考图-备份/棋盘/C1-棋盘全景俯视图.jpg` 为风格依据：连续土壤、磨损行军路径、90 个低矮石质交点、浅河道与不规则河岸、草丛、木栅栏、八座瞭望塔、南北营帐和风中旗帜。营帐放在双方底线外侧，保留将帅与九宫中的操作空间。

木质棋盘主体 `board_main` 已从游戏移除，仅作为历史候选保留。新地形由 `BattlefieldTerrain.tsx` 和共享 PBR 材质生成；新增原生 4K `battlefield_earth` 材质，游戏使用其 2K 运行包。落点间距 1.05、规则坐标不变，棋子底座位于 y=0.25。点击区域独立于美术网格。

原先的木质棋盘射线报告属于历史候选；当前使用游戏内 90 点屏幕布局及实际走子检查，不将旧报告作为新地形的证明。

## 动作

| 范围 | 制作方式 | 交付动作 |
| --- | --- | --- |
| 双方帅/将、仕/士、兵/卒，共 6 类 | Meshy 自动骨骼绑定与预设动作；恢复原 PBR；水平根位移移除 | 静置、攻击、受击、倒下，以及绑定附带的行走、奔跑 |
| 双方马、相/象、车、炮，共 8 类 | 本地制作局部关节和权重，保留完整复合模型 | 呼吸/警戒、头部与附属件轻动、冲击、机械后坐或投臂、受击和退场，以及行进循环 |

每类包含 6 个独立片段，共 **84 段**。人形底座分配给独立 `FixedPedestal` 骨骼，坐骑与机械底部顶点固定。局部动作是可编辑的骨骼变形，没有冒用 API 的双足绑定来处理四足与复合机械。局部关节方案不等同于每个轮轴、绳索和布片的物理仿真；模型轮廓与原贴图保持可辨认。

近景复核后，人形运行版另做本地修订：剑、盾与长兵器改为刚性持握权重，清理长兵器与脚部的扫描粘连，重新封平底座顶面。黑卒的下身衣甲和红仕的长袍统一跟随髋部并平滑衔接上身，避免预设动作把布料拉成长条；二者收小动作幅度，黑卒倒下时增加底座碰撞高度修正。此处理优先保持衣甲形状，不是腿部和布料的完整物理模拟，API 原始绑定与动作仍保留。

吃子共用一个时间轴：接近 → 攻击 → 命中 → 受击/退场 → 占位。命中时才触发音效、尘屑和可选震动；炮械从原位发射，目标退场后再前进。攻击者与目标底座在接近阶段保持间隔。完整吃子约 3.43 秒，简洁模式加速，关闭特效时约 90 毫秒。普通移动约 0.65 秒。

每个实例独立克隆骨架和播放器，静置相位错开。LOD 切换从同一时间轴继续，不重播动作；单调递增播放标识防止重开或悔棋后旧回调清除新状态。目标淡出不修改共享材质。

## 文件与来源

- 保留原来的 14 个静态高模源工程、8K Base Color / 4K 辅助 PBR，以及全部下载原件。
- 新增 14 个可编辑动画 `.blend`，记录在 [源工程索引](../../assets/source/production.json) 的 `animation_projects` 中。原始 FBX、绑定 GLB、预设 GLB 与行进片段保存在各棋子的 `motion/` 目录。
- 动画运行版为约 60k / 20k / 12k 三角面，纹理 4K / 2K / 1K；每档有 KTX2 和 WebP 备用，共 84 个动画 GLB，路径为 `public/assets/models/motion/`。
- 当前本地动画版本：红帅 v2、黑将 v4、红仕 v4、黑士 v2、红兵 v6、黑卒 v11；其余八类为 v1。版本号包含本地绑定和导出试修，没有对应新增 API 任务。
- 保留的静态运行文件加 7 套表面材质共 128 个；连同动画总共 **212 个 GLB**。这是全部精度及备用包的仓库总数，并非一次性加载量。
- [完整审计](production.json)、[静态路径清单](../../public/assets/production-manifest.json)、[动画路径清单](../../public/assets/motion-manifest.json)、[API 原件清单](api-archive.json)含来源、实际尺寸、体积与 SHA-256。

红兵曾生成一个过度翻转的倒地动作，已弃用并保留原件；最终采用向后倒下动作。API 原始根运动保存在下载原件中，可编辑源工程包含本地修订动作；运行 GLB 去除水平位移，游戏负责落点移动。所有修订均作用于派生文件，原件哈希保持不变。已核验 395 个 API 下载文件，共 7,026,140,516 字节；所有 212 个运行 GLB 的几何/动画字节、纹理尺寸和 KTX2 mipmap 校验通过。

## 验证与边界

最终检查：23 项前端单元测试、59 项 API 离线测试、lint 和生产构建通过；端到端测试 5 项通过、1 项按桌面/移动配置跳过。42 个动画档位、252 组动作/档位及各自 5 个采样时刻通过，固定底座最大数值位移约 1.9×10⁻⁸（检视尺度）。

| 测试环境 | 完整 / 简洁 / 关闭绘制次数 | P95 帧间隔 | 默认估计纹理驻留 |
| --- | --- | --- | --- |
| RTX 4060，1440×1000 | 103 / 100 / 100 | 约 5.7 ms | 394.4 MiB |
| 同机 Pixel 7 尺寸模拟 | 103 / 100 / 100 | 约 5.7 ms | 250.4 MiB |

窄屏地形与石块减少细分，正常加载时 23 个活动模型/材质全部就绪且无回退。人为阻断一个模型时其余 22 个继续显示，重试后恢复；阻断解码器时 23 个包全部切换 WebP。

- 前端单元测试覆盖规则、动画锁、过期回调、命中音效只触发一次、占位顺序和炮械原位发射。API 离线测试覆盖计费、重复执行、异常提交恢复、输入哈希、下载与价格异常。
- 实战检查确认 32 个实例的骨骼静置均发生变化，红兵与黑卒分别主动吃子、受击方播放匹配、悔棋、中途重开通过；双方炮械投射和吃子时切换画质通过。[兵卒流程](motion/game-flow.json)、[炮械流程](motion/cannon-flow.json)
- 三档动画检视检查 6 段动作多个时刻的固定底座顶点，验证 KTX2 实际解码和底座无漂移。[逐档结果](motion/browser.json)
- 桌面和 Pixel 7 尺寸模拟覆盖 90 点顶视、三种特效、画质切换、旋转、缩放、失败回退与重试。[性能](game/performance.json)、[镜头与画质](game/camera-quality.json)、[回退](game/fallback.json)
- 性能记录来自 Windows RTX 4060 的 Chrome/ANGLE D3D11。绘制包含主渲染及阴影；纹理驻留是估算值。**手机真机性能、发热和长时间稳定性仍待测**，没有将视口模拟当作手机 GPU 实测。
- 之前计划中的天空单面与远景原生 ≥2K 仍未达成：已有天空原生 1K，远景 1376×768。当前效果与接缝已检查，未以插值放大冒称原生 2K。
