# 车、马、炮动作补制验收

2026-09-06。本轮针对红黑双方的车、马、炮六个模型重新制作动作。此前四根骨骼按高度分配的轻微摆动，已替换为四足步态和独立机械部件关节；新版本已进入正式棋局和动作检视页。

| 模型 | 当前本地版本 | 关节 | 主要动作 |
| --- | --- | ---: | --- |
| 红马 | v6 | 23 | 四足交替行进、跑步、扬前蹄蓄势、骑手挺枪、低头退场 |
| 黑马 | v4 | 23 | 独立四足步态、颈部和尾部动作、扬蹄与骑手攻击 |
| 红车 | v6 | 38 | 双马八腿步态、两轮独立旋转、骑手出招、伞盖响应 |
| 黑车 | v4 | 38 | 双马步态、轮轴旋转、冲击和骑手动作 |
| 红炮 | v6 | 15 | 车轮转动、炮手操作、炮管沿自身轴线后坐与复位 |
| 黑炮 | v7 | 15 | 绞盘蓄力、投石臂摆动、发射与复位、炮手动作 |

每个模型保留 `idle / attack / hit / death / walk / run` 六段动作。底座独立固定，移动由棋局控制；原始高模、原始静态 GLB 与 PBR 图片未修改。机械零件和长兵器使用刚性权重，马腿与颈部使用关节间平滑权重。黑炮的下部框架和石箱保持固定。

棋局已移除马走子时整块底座升起的位移；红炮攻击时按炮管方向转向。炮弹从动画骨骼上的炮口/投石勺标记发出，红炮同时显示短促炮口闪光。发射位于吃子开始后 1.03 秒，命中位于 1.35 秒。六种更新资源使用版本参数及缓存键，避免继续使用旧动作。

验证证据：

- `vehicle-articulation.json`：18 个 GLB（六模型×三档精度）、108 段动作，共 4,428 次姿态采样。检查真实蒙皮顶点位移，确认步态、轮转、后坐、投石弧线和骑手攻击；固定底座位移为零，刚性部件边长变化小于 0.00001。
- `browser.json`：三个精度版本均通过六段动画播放、固定底座与三张 KTX2 PBR 贴图检查，浏览器无错误。
- `vehicles/game.json`：通过棋盘真实点击验证红黑马跑步、红黑车行进、两种炮的正确发射方向和起点、吃子完成与悔棋恢复。
- 完整资源审计：212 个运行时 GLB 的哈希、几何/动画配对、PBR 与 mipmap 检查通过；14 个原始棋子母版均通过未修改检查。
- 项目构建、lint 与 24 项单元测试通过。真机手机性能仍属于二期整体的独立验收项目。

演示文件：`vehicles/vehicle-motion.mp4` 和 `vehicles/vehicle-motion.gif`。演示直接录制已交付模型的中景版本；各模型先显示行进，再显示攻击/发射。

本轮全部使用本地 Blender 制作与导出，新增 API 费用为 0。每个版本目录均保存可编辑 `.blend`、三档 WebP GLB、KTX2 GLB 与 `runtime.json`。
