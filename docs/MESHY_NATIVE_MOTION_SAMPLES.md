## 对齐与装配修正

Meshy 会自动重新居中返回几何。通过相同 UV 的数万个顶点，实测黑卒需恢复约 `[+0.01546, -0.13165, +0.20504]` 米的三轴平移，旧流程仅恢复高度。新增匹配按实际输入逐件计算，检查对应点比例与误差，避免凭模型包围盒猜测。

原生骨骼与权重被转回原始表面；装备作刚性跟随，待机恢复原本坐姿/站姿，脚掌接触和原有固定底座另行校准。骑手动作保留生成的时长，并在末端回到起始姿态以便循环。因此样板是“Meshy 生成动作 + 本地适配”，不是未经处理的 API 原件。

## 验证与复现

- 原生流水线：`python -m unittest discover -s scripts/meshy -p test_*.py -q`，72 项通过。
- 页面与构建：`npm run lint`、`npm run build` 通过。
- 浏览器：`node scripts/check_native_motion_gallery.mjs` 检查每个展示动作、实际图像变化、固定底座和控制台错误；这些技术检查不替代自然度与接触质量验收。
- 样板清单及哈希：[staging.json](asset-reports/native-motion/staging.json)。浏览器证据在 `asset-reports/native-motion/browser/`。
- 入口：`scripts/meshy/native_motion.py plan|run --spec <JSON>`，支持生成、绑定、套用，仍受累计额度和余额下限约束。
- 归档：`assets/generated/meshy/<piece>/native/...` 为 API 返回；`motion/runtime/v*/` 为本地装配版本。游戏的 `public/assets/motion-manifest.json` 未被此次样板替换。
