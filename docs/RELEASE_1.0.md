# 玄甲棋局 1.0.0 发布说明

发布日期：2026-09-06 ｜ 标签：`v1.0.0` ｜ 许可证：GPL-3.0-or-later

以中国古代铠甲为造型语言的 3D 中国象棋。1.0 是首个正式版本：**本地双人对局**，含 14 类带骨骼动作与 PBR 的正式棋子美术、连续泥土战场与营地、移动与吃子特效、悔棋、重开、镜头模式与三档画质。

## 功能范围

- 完整本地双人对局：合法着法、将军、绝杀/困毙胜负判定（规则核心 elephantops）。
- 14 类棋子 × 红黑双方：静置/攻击/受击/退场/行走/奔跑六段骨骼动作，三档运行模型 + KTX2 纹理。
- 吃子可取消时间轴：命中音效、攻击、受击、退场与占位同步，支持中途悔棋与重开。
- 镜头：拖拽旋转、缩放、顶视切换；桌面与触屏可用。
- 画质：自动/精细/流畅三档，距离画质切换；单模型 404/解码失败自动回退程序化造型。
- 检视工具：棋子检视页、动作检视页、动作修整样板页（见 README「当前成品」）。

## 安装与运行

```bash
git clone https://github.com/wwweruu/cn_cheer.git
cd cn_cheer
```

运行时资产（约 2.1 GB）不进仓库，从 [Release v1.0.0](https://github.com/wwweruu/cn_cheer/releases/tag/v1.0.0) 下载以下 5 个必需附件，在**项目根目录**解压（包内路径以 `public/assets/` 开头）：

| 附件 | 内容 | 必需 |
|---|---|---|
| `cn_chess-1.0.0-assets-base.zip` | 环境、棋盘、解码器、清单、14 枚顶层棋子 GLB | ✅ |
| `cn_chess-1.0.0-assets-production-a/b.zip` | 静态/材质运行包（128 文件） | ✅ |
| `cn_chess-1.0.0-assets-motion-a/b.zip` | 动画运行 GLB（84 文件） | ✅ |
| `cn_chess-1.0.0-assets-native-motion.zip` | 动作修整评审样板 | 可选 |

解压后可用 `SHA256SUMS.txt` 校验完整性，然后：

```bash
npm install
npm run dev        # 开发预览
npm run build && npm run preview   # 生产构建
```

环境要求：Node.js 22+，支持 WebGL 2 的现代浏览器。

## 已知限制

1. **无存档/回放**：对局不能保存恢复（M4 候选实现仍在备份，计划 1.1）。
2. **无独立胜负表演**：绝杀/困毙有结果判定与提示，但无专门演出动画。
3. **不裁决竞赛争议**：长将、长捉、重复局面按自然规则处理，无裁判逻辑。
4. **移动端未经真机验收**：仅做过同机窄屏模拟；中档手机 30 FPS 目标待真机确认。
5. **动作数据残留**：motion 运行包 72 条 walk/run 首尾帧存在位移差（运行时由代码补偿基座漂移，检视页实测漂移 ≤1e-5，无可见滑步）；数据层面的清理列入 1.1。
6. 天空与远景未达原计划原生 2K；`general_red` rest 姿态双臂略外展（播放动作时正常）。
7. AI、联网、账户系统属三期范围，1.0 不含。
