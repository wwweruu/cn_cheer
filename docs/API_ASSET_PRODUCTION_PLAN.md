## 1. 统一制作规格

| 项目 | 本轮目标 | 验收方式 |
| --- | --- | --- |
| 风格 | 延续参考图的写实古代铠甲与战场沙盘；红方暖红/铜金，黑方深铁/冷灰，材质磨损尺度统一 | 红黑各一枚并排，在中性光和实际游戏光照下比较 |
| 棋子源资产 | 原始高模先验收完整轮廓与结构，保留无损原件；之后制作 8K Base Color 与 PBR、整理源工程 | 以官网红帅为细节基准，检查披风、底座、冠冕、手脸、甲片、衣纹；再检查实际纹理和 UV |
| 棋盘源资产 | 主体、红营、黑营、瞭望塔共 4 类模型，Base Color 8K；阵营营帐分别制作，瞭望塔可实例复用 | 俯视、45°、最低允许视角检查；不挡落点和棋子 |
| 场景表面 | 6 套可复用材质，Base Color 4K；附法线、金属度与粗糙度，按材质需要合并通道 | 3×3 平铺与掠射光检查接缝、光照烘焙痕迹和凸凹方向 |
| 运行版本 | 棋子和棋盘导出桌面高画质 4K、移动端 2K；8K 原件用于制作及单资产近景检视 | 按设备加载相应版本；相同模型实例共享贴图，不默认让整盘加载 8K |
| 几何 | 源高模不设 20k 上限；运行版以 20k/8k/3k 为初始优化目标，保留底座与可拆部件 | 先核对高模还原度，再检查运行版轮廓损失、绘制单元和真机性能；不能为凑面数删掉主要结构 |
| 字与棋线 | 底座棋名、楚河汉界、九宫斜线、格线由确定性字体/几何生成 | 逐字核对；全部 90 个交叉点与游戏坐标一一对应 |

`texture_resolution` 在官方说明中控制的是 **Base Color** 分辨率，不能把请求 8K 当成每张 PBR 辅助图都一定是 8K。保存每张实际分辨率；不能通过把低分辨率图插值放大来标记“原生 8K”。高精度还要求正确 UV 分配与可见细节。[多图建模贴图参数](https://docs.meshy.ai/en/api/multi-image-to-3d)

当前参考图中的黑方炮是配重式抛石机，马包含骑手；这些结构差异必须保留。红黑不能只换颜色，机械复合件不能按普通双足人形处理。

**底座为必保留结构。** 原始高模、贴图后模型和运行版逐级核对底座的整体形状、边饰、棋名与人物站立关系。任何阶段丢失或明显变形都不能通过；当前缺底座的 v1/v2 API 原件均不作为后续源模型。

天空六面需统一地平线、光源方向、曝光和相邻边缘，再在真实立方体投影中检查拼缝。现有 E1 只能作为风格参考；2D 图像 API 没有文档化的 2:1 等距柱状全景参数，也不保证 360° 连续或 HDR 数据。交付采用 **LDR 天空背景 + 独立场景灯光**，不把普通 JPG 改名为 HDRI。若六面一致性不达标，从图像返工额度修订，并可降低天空细节后重新验收。

图像 API 暂未公开固定 4K/8K 输出参数：天空单面目标至少 2K、远景长边目标至少 2K，按实际返回尺寸和观看距离验收；不足就补充制作，不能宣称天然达到目标。地面等需要明确 4K 的表面使用上面的 Retexture 路线。两张氛围图保留 alpha，避免生成不透明矩形。[图像生成参数](https://docs.meshy.ai/en/api/text-to-image)、[图像编辑参数](https://docs.meshy.ai/en/api/image-to-image)

## 4. 总预算与控制规则

## 5. 工程交付与排期口径

- API 原件：沿用 `assets/generated/meshy/`，扩展为按资产种类/资产键/工序/版本保存。
- 源工程：`assets/source/production.json` 索引 18 个已打包纹理的 `.blend` 和 6 套材质；实际文件与母版按资产/版本保存在 `assets/generated/meshy/`。当前为完整静态网格，运动部件拆分与绑定继续列入动画阶段。旧源文件保留版本。
- 棋子运行文件：沿用 `public/assets/models/`；棋盘与场景拟分别使用 `public/assets/board/`、`public/assets/environment/`，接入时登记完整 manifest。
- 验收材料：`docs/asset-reports/`，每枚/每套包含近景和游戏截图、实际参数、费用、质量问题与复核结论。

顺序依赖为 **S0 → S1 → S2/S3/S4 → S5**。S2～S4 可在各自样板通过后交错推进，但付费调用仍按客户端安全队列执行。S0 初估 1～2 人天，S1 整理与集成初估 2～4 人天；其余制作时间在样板通过后按真实返工率重估。API 排队、生成等待与人工制作时间分别记录，不把积分足够等同于固定日期交付或全部资产一次达标。
